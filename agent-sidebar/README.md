# Agent sidebar для Ghostty (форк, PoC)

Ветка `agent-sidebar` = Ghostty **v1.4.0** + боковая панель с вертикальными
вкладками и статусами агентов, по мотивам сайдбара Intelligent Terminal 0.3.

> **Статус: PoC, собран и запущен на Mac (macOS 27, Xcode 26.2, Zig 0.17.1).**
> Что проверено запуском, а что только компиляцией, перечислено в разделе
> «Что проверено».

## Что есть

Слева в каждом окне терминала панель «Tabs»:

- вертикальный список вкладок окна: иконка, заголовок, под ним метаданные;
- иконка агента (✳ у Claude Code), во время работы агента вместо неё крутилка;
- статус агента: `Working…` / `Needs you` (с текстом запроса) / `Done` / `Idle`;
- оранжевая точка у вкладки, которая ждёт вас или звенит (bell);
- текущая папка, git-репозиторий, ветка, число изменённых файлов;
- меню настроек (иконка с ползунками): «Agents only», «Recent agent sessions»,
  набор метаданных, «Hide native tab bar»;
- поиск по вкладкам, кнопка «+» (новая вкладка), крестик при наведении;
- правый клик по вкладке: переименовать, скопировать папку, закрыть, закрыть
  остальные;
- раздел «Recent agent sessions»: последние сессии Claude Code из
  `~/.claude/projects`, клик открывает новую вкладку с `claude --resume <id>`;
- ширина меняется перетаскиванием разделителя, кнопка в шапке сворачивает
  панель в узкую полоску;
- кнопка ✨ в шапке открывает справа **агентскую панель** (чат с агентом, см.
  ниже);
- полоса внизу сайдбара, когда команда в выбранной вкладке завершилась с
  ошибкой: «Command failed — Fix» → «Analyzing…» → «Fix ready — Run».

Пункты меню View и горячие клавиши:

| Действие | Клавиши |
|---|---|
| Show Tab Sidebar | ⌃⌘S |
| Show Agent Tabs Only | ⌃⌘G |
| Go to Next Tab Needing Attention | ⌃⌘A |
| Open Agent Pane | ⌃⌘P |
| Fix Last Error | ⌃⌘. |

Кроме сайдбара:

- **свёрнутый сайдбар** — колонка иконок вкладок с номерами; родная полоса
  вкладок скрыта в обоих состояниях;
- **строка статуса** под терминалом во вкладках с Claude Code: состояние
  агента, размер контекста последнего запроса, токены за сессию, модель
  (данные из журнала сессии в `~/.claude/projects`);
- **уведомления macOS**, когда агент ждёт ответа или закончил во вкладке,
  на которую вы не смотрите; клик открывает вкладку; свой звук для «ждёт» и
  для «готово»;
- **непрочитанное**: вкладка, где агент закончил без вас, держит зелёную
  точку, пока вы её не откроете; на иконке в Dock — число вкладок, которые
  ждут вас или закончили; во вкладке со сплитами панель с ждущим агентом
  обведена; ⌃⌘A ведёт к следующей такой вкладке;
- **восстановление прошлой сессии**: при запуске вопрос, вернуть ли вкладки
  прошлого запуска; они открываются в своих папках, а там, где шёл Claude
  Code, выполняется `claude --resume <id>`;
- **окно настроек** (⌘, или меню с ползунками → Settings…): тема, шрифт,
  фон, курсор, окно, восстановление, сайдбар, агенты. Значения пишутся в
  `~/.ghostty-agents/settings.conf`, который загружается поверх конфига
  Ghostty; сам конфиг не переписывается.

## Агентская панель и исправление ошибок

Кнопка ✨ в шапке сайдбара (или ⌃⌘P) открывает справа сплит. Что в нём
запускается, выбирается в Settings → Agents → Agent pane:

- **Claude Code** (по умолчанию): `claude` в интерактивном login-shell;
- **WTA chat**: чат WTA из [AgentTerm](https://github.com/IRadJaI/AgentTerm)
  (ветка `macos-port`), нужен собранный `wta-ghostty` в PATH;
- **Custom command**: своя команда.

Если команда в shell завершилась с ошибкой, внизу сайдбара появляется
«Command failed (exit N) — Fix». Кнопка (или ⌃⌘.) открывает Claude Code в
сплите и передаёт ему конец вывода терминала. Код 130 (ctrl+c) ошибкой не
считается. Нужна shell-интеграция Ghostty (для zsh, bash и fish включена по
умолчанию). При выбранном WTA ошибки определяет и исправляет сам WTA.

### Управляющий сокет

Форк слушает Unix-сокет `$TMPDIR/ghostty-agent-<uid>/<bundle-id>.sock`
(права 0600, каталог 0700) и передаёт путь дочерним процессам в переменной
`GHOSTTY_AGENT_SOCKET`. Через него доступны: список окон, вкладок и панелей,
чтение текста панели, сплит и новая вкладка, ввод текста, фокус и закрытие,
поток событий (в том числе «команда завершилась с кодом N»), а также
`open_settings`, `fix_last_error` и `snapshot_window` (снимок окна в PNG,
удобен для проверки интерфейса без разрешения на запись экрана). Любой процесс
вашего пользователя может подключиться к сокету и, например, ввести текст в
терминал — так же, как это позволяет AppleScript-интерфейс самого Ghostty.

## Готовая сборка из GitHub Actions

Каждый пуш в ветку собирает Debug-приложение. Скачать его можно со страницы
запуска workflow `agent-sidebar` (раздел Artifacts,
`Ghostty-agent-sidebar-debug`): <https://github.com/IRadJaI/ghostty/actions/workflows/agent-sidebar.yml>

Приложение подписано только ad-hoc подписью, без сертификата разработчика,
поэтому после распаковки снимите карантин:

```bash
unzip Ghostty-agent-sidebar-debug.zip      # внутри ещё один zip с Ghostty.app
xattr -dr com.apple.quarantine Ghostty.app
open Ghostty.app
```

Это Debug-сборка: у неё свой bundle id (`com.mitchellh.ghostty.debug`), она
не мешает установленному Ghostty, работает медленнее и показывает жёлтую
плашку.

## Сборка на Mac

Нужны Xcode 26 (с macOS 26 SDK и Metal Toolchain) и Zig 0.17.x — это
требования самого Ghostty 1.4, см. `HACKING.md`.

```bash
git clone -b agent-sidebar https://github.com/IRadJaI/ghostty.git
cd ghostty

# 1. Ядро (GhosttyKit). Долго только в первый раз.
zig build -Demit-macos-app=false

# 2. Приложение. Debug-сборка имеет отдельный bundle id
#    (com.mitchellh.ghostty.debug) и не мешает установленному Ghostty.
xcodebuild -project macos/Ghostty.xcodeproj -scheme Ghostty \
  -configuration Debug SYMROOT="$PWD/macos/build" build

open macos/build/Debug/Ghostty.app
```

Debug-сборка медленная и показывает жёлтую плашку — это штатное поведение
Ghostty. Для повседневного использования собирайте релизную:

```bash
zig build -Doptimize=ReleaseFast -Demit-macos-app=false -Dxcframework-target=native
xcodebuild -project macos/Ghostty.xcodeproj -scheme Ghostty \
  -configuration ReleaseLocal SYMROOT="$PWD/macos/build" \
  ARCHS=arm64 ONLY_ACTIVE_ARCH=YES build
ditto "macos/build/ReleaseLocal/Ghostty Agents.app" "/Applications/Ghostty Agents.app"
```

Релизная сборка форка — отдельное приложение «Ghostty Agents»
(`com.iradjai.ghostty-agents`): ставится рядом с обычным Ghostty и читает тот
же конфиг. Обновления из upstream в ней выключены, обновляется пересборкой.
`-Dxcframework-target=native` и `ARCHS=arm64` собирают только под
архитектуру этого Mac; без них нужна универсальная сборка ядра.

Если `xcrun metal` не находится, поставьте компонент Xcode:
`xcodebuild -downloadComponent MetalToolchain`.

Если `zig build` падает с `TlsInitializationFailed` при загрузке
зависимостей (встроенный TLS Zig не со всеми сетями работает), скачайте их
другим способом: для каждой строки `build.zig.zon.txt` выполните `curl`,
отдайте файлы локальным HTTP-сервером и вызовите `zig fetch
http://127.0.0.1:<порт>/<файл>`. В Zig 0.17.1 архив в `~/.cache/zig/p` после
такого `zig fetch` содержит лишний верхний каталог; его нужно перепаковать
без этого каталога, иначе сборка сообщит о несовпадении хеша.

## Статусы Claude Code (хуки)

Без хуков сайдбар только узнаёт агента (по процессу в терминале и по
заголовку). Статусы «работает / ждёт вас / готово», уведомления, строка
статуса и возобновление сессий работают через хуки. Включаются в Settings →
Agents → Turn On, или из репозитория:

```bash
agent-sidebar/install-claude-hooks.py            # установить
agent-sidebar/install-claude-hooks.py --print    # показать, что будет записано
agent-sidebar/install-claude-hooks.py --remove   # убрать
```

Установщик дописывает шесть хуков в `~/.claude/settings.json` (существующие
не трогает, перед изменением делает резервную копию) и копирует скрипт в
`~/.ghostty-agents/bin/ghostty-agent-hook`. Приложение при запуске обновляет
эту копию, если в нём более новый скрипт. После установки перезапустите
открытые сессии Claude Code.

Как это работает: Claude Code на событиях (`UserPromptSubmit`, `PreToolUse`,
`Notification`, `Stop`, `SessionStart`, `SessionEnd`) запускает скрипт. Тот
находит tty терминала и пишет `~/.ghostty-agents/status/<tty>.json` с
состоянием и идентификатором сессии. Сайдбар раз в секунду читает эти файлы
и сопоставляет их с вкладками по tty. Наружу ничего не отправляется.

## Что проверено

Запуском на Mac, по снимкам окна и скриншотам:

- сайдбар развёрнутый и свёрнутый, переключение между ними, фон на всю
  высоту окна, прозрачность, заголовок окна справа от сайдбара;
- изменение ширины перетаскиванием;
- управляющий сокет: `ci-socket-test.py`, 13 проверок из 13;
- окно настроек: открывается, читает значения из конфига, выбранное
  значение записывается в файл (применение на лету глазами не подтверждено);
- вопрос о восстановлении и открытие вкладок в их папках; запуск
  `claude --resume` в существующей вкладке;
- статус «Working…» в сайдбаре и строка статуса с токенами — на
  подставленном файле статуса и настоящем журнале сессии;
- точка непрочитанного, счётчик на иконке в Dock (появляется и снимается
  при переходе на вкладку), обводка ждущей панели — на подставленных файлах
  статуса;
- хук-скрипт: идентификатор сессии, в том числе при обрезанном многобайтном
  вводе.

Только компиляцией, вживую не проверено:

- уведомления macOS и переход по клику на них;
- статусы и строка статуса от Claude Code, запущенного внутри форка;
- возобновление настоящей сессии Claude Code после перезапуска;
- плашка «Command failed» и кнопка Fix;
- подсказки при наведении, контекстное меню вкладки, поиск, горячие клавиши
  ⌃⌘S / ⌃⌘G / ⌃⌘A / ⌃⌘P / ⌃⌘.;
- `macos-titlebar-style = tabs` и `hidden`, полноэкранный режим, несколько
  окон.

## Известные проблемы и ограничения

1. **Восстановление сессии.** Возвращаются вкладки, а не сплиты; все вкладки
   открываются в одном окне; возобновляется только Claude Code. Сохранённая
   вкладка считается уже открытой, если есть вкладка с тем же каталогом и
   shell на переднем плане.
2. **Строка статуса.** Процента заполнения контекста нет: размер окна
   контекста в журнале сессии не записан.
3. **Заголовок окна.** При развёрнутом сайдбаре системный заголовок и иконка
   папки скрыты, вместо них своя надпись справа от сайдбара; шрифт заголовка
   из конфига (`window-title-font-family`) к ней не применяется.
4. **Ручка перетаскивания панели** (три точки вверху панели) — штатная в
   Ghostty 1.4, рисуется поверх первой строки. Отключается в Settings →
   Behavior → Splits.
5. **Скрытие родной полосы вкладок.** Полоса — приватная часть AppKit. Если
   она ведёт себя странно, выключите «Hide native tab bar».
6. **Распознавание агента по процессу** (`proc_name`). Если Claude Code
   запущен через `node`, без хуков он распознаётся только по заголовку «✳».
7. **Размер окна.** Ширина сайдбара добавляется к ширине нового окна; высота
   строки статуса и панель, вытащенная в новое окно, не учтены.
8. **Ключи настроек** переименованы (без точек) без переноса старых значений.
9. **`send_text`** в сокете вставляет текст как из буфера обмена: при
   bracketed paste перевод строки команду не выполняет.

## Чего пока нет

- перетаскивания вкладок в сайдбаре, закрепления, превью содержимого;
- статусов для агентов, кроме Claude Code (остальные только распознаются);
- автоматических тестов, кроме теста сокета и скриншотов в CI.

## Синхронизация с upstream

Патч задевает несколько мест upstream-кода (по 1–6 строк в четырёх файлах),
поэтому переход на следующую версию — это `git rebase` ветки на новый тег.
Конфликты возможны только в этих местах; они помечены комментарием
`agent-sidebar`.
